### 1.2 目标与闭环

为运营提供可操作、可保存、可追溯的单品经营工作台，为主管提供审批及服务配置入口。完整业务顺序为：

`商品建档与竞品录入 → 智能诊断 → 创意方案生成 → 异步素材制作与审核 → 投放建议与人工审批 → 经营数据回填 → 闭环复盘 → 下一轮诊断`

每阶段必须展示当前结果、未满足条件、下一步操作及失败原因。浏览历史区域不受阶段顺序限制；生成、确认、提交等写操作必须符合后端前置条件。失败保留前面阶段已有成果，不能把整个轮次重置为空。

### 1.4 技术与视觉基线

| 类别 | 已确认选择及用途 |
| --- | --- |
| 前端基础 | Vue 3、JavaScript、Vite、Vue Router。 |
| 通用组件 | Element Plus，用于导航、表单、表格、上传、抽屉、弹窗及状态标签。 |
| 图表 | ECharts，用于经营趋势、A/B 对比及目标与实际对比。 |

| 服务连接 | `/api` 通过 Vite 代理访问 FastAPI；独立 Python worker 与 MySQL 8.0 承担后台执行及持久化。 |

界面采用浅色中文管理后台，蓝色主调沿用 Element Plus 默认主题，左侧导航、顶部用户信息、主体内容区。主操作使用蓝色；成功、警告、错误配合文字标签，不能仅靠颜色表达。基础正文采用 14px，页面间距以 16px／24px 为基准；长文本换行，编码、金额和状态列保持清晰可读。页面提示使用业务语言，技术契约仅放在本需求文档及开发资料中。

桌面为完整操作终端，必须检查 `1366×768` 和 `1920×1080`、浏览器缩放 100% 的布局；浏览器验收使用 Windows 上当前稳定版 Chrome 与 Edge。侧栏可折叠，表格在容器内横向滚动，编辑器和弹窗不得挤出可操作区域。窄屏保留基本访问、纵向堆叠及表格滚动，不要求手机完整业务验收。仅需要满足现有技术栈的简洁实现，不新增框架或复杂设计系统。

## 2. 角色与信息架构

### 2.1 FE-AUTH：登录与会话

登录页提供账号、密码、登录按钮、请求中状态和错误提示。必填项空白时阻止提交；密码不回显、不进入 URL 或日志。登录成功获取 JWT 和用户信息，进入运营大盘；若来自有效的站内访问地址，则返回该地址并再次检查权限。

前端凭据默认保存在 `sessionStorage`，请求使用 Bearer token；不把前端存储中的角色当作接口授权依据。有效期按后端默认八小时处理。刷新时查询当前用户，校验通过后恢复页面；退出清除凭据、业务缓存、轮询和文件预览资源。401 时停止后续业务请求并进入登录流程；403 显示无权限说明及返回入口，不误当作登录失败。

会话过期时，同一标签页的未提交普通编辑内容可暂留内存，重新登录且确认是同一用户、同一业务上下文后才允许恢复；服务配置密钥、账号密码不进入草稿。退出、切换用户或关闭页面时清除这些暂存内容，不跨用户恢复。

### 2.2 FE-NAV：导航与拟定前端路由

以下为本文确定的前端导航默认值，均待实现；它们不是新增后端 API。

| 路由 | 页面／入口 | 可访问角色 |
| --- | --- | --- |
| `/login` | 登录页。 | 未登录可进入；已登录默认进入大盘。 |
| `/dashboard` | 运营大盘与店铺概览，登录后默认首页。 | 两角色。 |
| `/workbench/:productId` | 商品智能运营工作台。 | 两角色；操作按权限细分。 |
| `/imports` | 批量导入与数据中心。 | 两角色；主管仅下载模板、查看结果。 |
| `/settings` | 系统与服务配置。 | 仅主管。 |

根路径导航至大盘，未知地址展示未找到页面及返回入口。侧栏包含大盘、商品工作台、导入中心；主管另见配置入口。工作台入口先展示商品选择／检索状态，选定商品后进入含商品标识的地址；没有商品时给运营提供建档入口，主管看到只读空状态。

工作台地址查询参数保存 `roundId` 和 `tab`，`tab` 取 `diagnosis`、`creative`、`review`，分别对应三大分区。首次进入未指定轮次时选择该商品最新轮次；尚无轮次时由运营显式建立首轮，不因浏览自动创建。无效或不属于该商品的轮次应提示并要求选择有效轮次，不能悄悄展示其他商品内容。

## 3. 页面详细要求

### 3.1 FE-DASH：运营大盘与店铺概览

**入口与筛选**：两角色登录后进入。默认近七个业务日期，支持起止日期及全部／单个店铺；明确显示范围。查询按钮应用筛选，重置恢复默认。商品检索按名称或编码，店铺筛选后仅展示关联商品，分页默认每页 20 条，可选 20／50／100；改变筛选返回第一页。

| 区域 | 必须展示 | 操作与结果 |
| --- | --- | --- |
| 多店铺卡片 | 平台、名称、店铺编码、脱敏授权状态、关联商品数、在售动销率、预警数量。 | 点击店铺应用筛选；主管可进入对应配置区域，运营无授权维护入口。 |
| 汇总指标 | 商品总数、在售动销率、曝光、点击、订单、GMV、广告花费、CTR、转化率、ROI。 | 指标随范围同步更新，展示口径及单位。 |
| 经营走势 | 按业务日期展示曝光、点击、订单、GMV、花费及可切换比率；不同单位分开呈现。 | 悬浮提示日期、数值及当前店铺范围；无数据不绘制假曲线。 |
| 库存预警 | 店铺、商品、规格、平台 SKU、当前库存、阈值。 | 点击进入该商品档案并定位店铺规格；库存等于阈值也预警。 |
| 商品列表 | 商品编码、名称、品类、在售价格带、关联店铺及进入工作台入口。 | 点击进入对应商品；快速录入与批量导入仅运营可执行。 |
| 快捷操作 | 创建店铺、商品快速录入、商品／库存／经营数据导入。 | 成功后重新读取相关列表与指标，不能仅改页面计数。 |

全局商品数按统一档案去重，店铺商品数按关联商品统计，不能把两店铺的同款算为两份全局商品。全局动销按在售商品去重、在选定期间检查是否有订单；库存始终按店铺 SKU 分别展示。

空数据区提供范围说明及运营录入入口；局部查询失败仅在对应区域显示错误和重试，不能把错误替换为零。店铺不存在或商品已不可访问时保留返回列表的入口。

### 3.2 FE-CTX：商品工作台框架

顶部固定商品名称／编码、关联店铺摘要、轮次选择、当前阶段、来源报告入口。店铺选择只影响店铺上架、库存、实验和经营范围，不把统一商品档案拆成不同商品。

下方显示业务步骤导航，以及“档案与诊断”“创意与素材”“投放与复盘”三个标签页。点击步骤进入相关标签页并定位对应区域；顶部步骤在较窄桌面可横向滚动，不要求三栏同屏。

| 步骤 | 操作门槛及页面说明 |
| --- | --- |
| 建档与竞品 | 商品属性、价格和规格待补齐时列出缺项；竞品至少一份经运营核对才能诊断。 |
| 智能诊断 | 输出五类结构完整、保存后经运营确认，才允许创意引用。 |
| 创意方案 | 至少三组主图及三套脚本完整；选定制作项并确认版本后才允许提交素材任务。 |
| 素材制作与审核 | 展示任务成功与素材审核两个状态；选择投放素材需可用且未归档，完整演示含图片及视频。 |
| 投放与审批 | 选择商品关联店铺及可用素材，完整建议提交后仅主管批准；驳回可编辑重提。 |
| 经营回填 | 已批准实验及有效组别才能保存；日期必须在实验周期内。 |
| 复盘 | 周期结束、有有效数据、范围已确认；缺日期或字段应说明。 |
| 下一轮 | 已确认报告和有效优化行动；保留来源报告及历史轮次。 |

阶段及未满足条件以服务端业务判断为准；前端不可仅凭按钮点击或本地缓存宣布阶段完成。未满足条件时仍可查看该区域说明及历史记录。生成结果返回后重新核对商品、轮次和上游版本；已过期结果不得接入当前界面。

### 3.3 FE-PRODUCT：商品、店铺、规格及库存

档案区支持创建及编辑统一商品、维护 SKU、关联店铺上架、维护映射与库存。快速录入先保存基础档案，再进入工作台补全，基础信息保存不代表建档阶段完成。

| 对象 | 字段／展示内容 | 校验与保存行为 |
| --- | --- | --- |
| 店铺基础档案 | 店铺编码、名称、平台、平台接入标识；授权状态只读。 | 基础标识必填，编码唯一；运营维护，模拟授权由主管另行配置。 |
| 统一商品 | 商品编码、名称、品类、基础售价、基础属性、主推 SKU。 | 编码／名称／品类／售价必填，售价为正数；主推 SKU 必须来自本商品，未建立规格时可后续选择。 |
| 商品 SKU | 商品内规格编码、颜色／尺码等规格属性。 | 编码及规格组合清晰可辨；编码在商品内唯一；不能选择其他商品的 SKU。 |
| 店铺上架记录 | 关联店铺、平台商品标识、在售状态及售价信息。 | 店铺与商品组合唯一；店铺必选，平台标识需补齐；有效售价为正数，价格展示区分基础价与店铺价。 |
| 平台 SKU 映射 | 本商品 SKU、平台 SKU 标识、店铺规格售价、库存、预警阈值。 | SKU 与当前上架商品归属一致；同上架规格映射唯一；售价为正数，库存和阈值为非负整数。 |
| 库存调整 | 当前库存只读、目标库存、调整原因。 | 展示预期差额；运营提交目标值及原因，保存成功后重新读取库存和流水。 |
| 库存流水 | 前值、后值、差额、原因、来源、操作人、操作时间。 | 按选定店铺规格查询，保存失败不得显示已完成流水；操作时间按本地时区显示。 |

上架与映射按店铺切换显示，调整一店库存不影响另一店。新映射的库存初始化也必须留下可追溯库存流水；库存已有后统一走独立调整接口，不用普通资料编辑绕过流水。经营数据回填不自动扣库存。

重复编码、无效价格、负库存、错误 SKU 归属定位至具体字段，保留未提交值。库存保存失败时回显原保存值并保留调整输入供修正，不把本地预估当作已保存库存。

### 3.4 FE-DIAGNOSIS：竞品与智能诊断

**竞品录入**提供手工表单、导入入口和公开文本解析入口。竞品字段包括编码、名称、平台、售价、规格／关键属性、核心卖点、公开来源 URL／说明和核对状态；编码、名称及售价必填，售价为正数，诊断前关键参数需齐备。来源说明须区分公开资料与合成教学资料。

解析流程为：粘贴文本 → 请求解析 → 展示待核对字段 → 运营编辑 → 保存并标记已核对。解析结果不能自动成为已核对事实；表格导入也先进入待核对状态。竞品对比表同时展示本商品与已核对竞品的价格、规格和关键卖点。

| 诊断区域 | 必需内容及操作 |
| --- | --- |
| 生成输入 | 显示当前商品、轮次、资料就绪情况；可填写运营补充要求，下一轮展示带入行动及来源。 |
| 目标客群 | 客群画像和适用场景。 |
| 价格带分析 | 商品与竞品价格带、竞争力分析；建议价格不能自动修改售价。 |
| 核心卖点矩阵 | 商品卖点、竞品差异及支持资料，表格或结构化列表展示。 |
| 转化卡点 | 潜在阻碍和依据，区分诊断推测与已测事实。 |
| 优化方向 | 可读的改进建议，供创意引用。 |
| 编辑及版本 | 在线编辑、显式保存、确认、归档、历史版本查看；显示状态、版本和来源。 |

生成前须商品属性和价格齐备，至少一份竞品已核对。生成期间展示等待状态，成功后为草稿；保存后刷新可重新读取编辑内容，五类结构完整后允许运营确认。归档退出新的可引用选择，已引用历史保持可追溯。

模型调用失败或结构缺失应显示具体原因／缺字段和重试入口，保留已有内容。上游资料或版本变化由后端返回冲突说明，前端提示重新核对，不默默使用旧输入生成结果。

### 3.5 FE-CREATIVE：主图方向与视频脚本

进入“创意与素材”后，先选择当前商品本轮可引用的已确认诊断，展示版本摘要；未确认时给出返回诊断入口。运营可补充期望风格和要求，再生成创意。

| 类型 | 数量与结构 | 编辑呈现 |
| --- | --- | --- |
| 主图方向 | 至少三组差异化方向；每组含构图版式、核心文案、主打卖点、视觉呈现建议。 | 卡片列表及详情编辑区；四个结构字段分别可编辑，不以一个无结构文本块代替。 |
| 视频分镜脚本 | 至少三套；每套含开头三秒钩子、分镜画面描述、口播台词、促单转化话术。 | 脚本列表及按镜头展示的编辑区；画面与台词对应显示，保留脚本整体钩子与促单字段。 |

Quill 承担富文本编辑，保存结构化字段及对应编辑内容；编辑器中删除必需内容后也必须重新校验。卡片显示选定状态，运营可选择制作方向／脚本，保存选择及内容，再确认版本。不同主图不能用相同设计重复三次凑数。

缺字段或数量不足时列出具体项，不允许确认；允许修正或重新生成并保留已有版本。重新生成是明确按钮操作，刷新页面不生成新内容。确认后提供“创建图片任务”“创建视频任务”，先展示所引用版本及选定项再提交。

### 3.6 FE-TASK：图片及视频异步任务

创建任务表单包含任务类型、已确认创意版本、选定主图／脚本、制作选项；演示模式下可选择成功或故障场景并标注教学用途。提交成功后显示后端任务标识和排队状态；请求已受理不代表素材已经生成。

| 服务端状态 | 中文展示 | 运营操作 |
| --- | --- | --- |
| `pending` | 排队中；展示提交时间、排队等待时间。 | 取消。 |
| `running` | 生成中；展示本次开始时间、执行耗时与截止信息。 | 取消。 |
| `succeeded` | 生成成功；提供对应素材入口。 | 查看素材，不直接标为可用。 |
| `failed` | 执行失败；展示原因和自动重试情况。 | 仅最终失败且自动重试耗尽时人工重试。 |
| `timeout` | 执行超时；展示尝试期限与原因。 | 仅最终超时且自动重试耗尽时人工重试。 |
| `cancelled` | 已取消；展示取消时间及原因信息。 | 查看历史，不继续自动尝试。 |

时间线显示每次尝试序号、排队／开始／结束时间、结果、错误原因及重试，显示任务提交时的超时、重试配置和关联原任务。默认并发配额二、单次执行超时六十秒、首次以外最多两次自动重试；队列时间不能计入执行超时。

默认每两秒查询状态。一次尝试失败／超时但仍会自动重试时继续跟踪，直到服务端确认任务最终失败／超时或进入成功／取消。不能只看到 `failed` 字样就停轮询；终态识别需要服务端明确重试预算和调度情况。人工重试创建关联原任务的新任务，界面保留旧时间线并跟踪新任务。

页面离开、切换上下文或退出时停止该视图轮询；后端任务继续执行，重新进入时读取持久化状态。轮询请求不重叠；查询失败展示“状态更新失败”和最后更新时间，不把网络失败改成任务失败。网络恢复后重新查询，不重复提交任务。

取消发起后显示处理中，成功后以服务端 `cancelled` 为准；若已完成则展示冲突结果并刷新。迟到结果不得使已取消卡片变成功，也不得新增素材。没有真实进度时只展示阶段与耗时，不自行增长百分比。演示需覆盖成功、首次失败后成功、持续失败耗尽、超时、排队取消、运行中取消及迟到结果。

### 3.7 FE-MATERIAL：素材库与审核

素材网格按当前商品和轮次过滤，提供图片／视频、审核状态、标签及归档筛选。默认显示未归档素材，包括待审核、可用、已驳回；历史筛选可查看归档项。

每张卡片展示缩略图或视频封面、类型、素材版本、创意来源版本、任务入口、审核状态、标签和“演示素材”标识。详情展示图片大图／带控件可播放视频、来源、审核意见与记录、版本及历史引用。文件加载失败显示原因和重新加载，不以空白缩略图判定审核通过。

运营可标记可用、驳回、维护标签或归档。审核成功后刷新记录；生成成功和审核通过分别记录。归档前提示退出新投放选择且保留历史，归档成功后从默认列表退出，在历史视图仍可查看文件和审批引用。

投放素材选择器仅列可用且未归档的合规素材，并显示归属与版本；提交时后端再校验。图片／视频文件的修改通过编辑创意和新任务生成新版本，不能替换旧文件。主管仅预览及查看审核记录。

### 3.8 FE-AD：投放建议、主管审批与实验

进入“投放与复盘”，先选择该商品的关联店铺。生成前核对已确认内容、阶段及可用素材。选择器不得纳入其他商品素材或归档素材，不同店铺可引用该商品符合业务归属规则的素材。

| 录入／展示项 | 页面要求 |
| --- | --- |
| 商品、轮次、店铺 | 当前商品及轮次只读，店铺从关联记录选择；明确建议和实验归属。 |
| 人群定向与人群包推荐 | 结构化展示，可编辑并保存，不连接真实广告账户。 |
| 出价策略、预算、周期 | 可编辑；金额合法、非负，日期范围有效；具体业务限制由后端校验并反馈，不自造平台规则。 |
| A/B 分组 | 展示组编码、组策略、素材版本组合、出价／预算和组目标；防止跨实验混用同名组。 |
| 目标指标 | CTR、转化率、ROI、详情页跳失率等，明确百分比／倍数、目标方向和周期。 |
| 建议版本及状态 | 草稿、待审批、已驳回、已批准；展示创建／修改及上游引用信息。 |
| 审批记录 | 决定、审批人、时间、意见及审批的建议版本。 |

运营流程为生成 → 编辑保存 → 确认内容 → 提交指定版本审批。所有 AI 文字建议须有在线编辑、运营内容确认及归档入口；内容确认与保存分离，明确确认的是当前建议文字版本，不等于主管批准。运营内容确认接口已按§5.3同步确定，实施时核对实际 Schema，不自造“已批准”状态。提交后显示待审批；运营只能查看审批状态，不出现批准入口。

主管可查看完整提交版本及素材快照，输入审批意见，点击“批准建议”或“驳回调整”；驳回原因必填，批准也保存审批意见字段。请求中防重复点击，成功后展示审批记录；批准同时建立对应实验，不再由前端另发创建实验请求。

待审批版本不能原地修改；运营选择调整时建立新版本并重新提交，旧提交记录保持。驳回后支持调整重提；批准后调整同样建立新草稿并重新审批，旧批准、实验和经营数据保留。历史版本必须能查到其审批意见。

实验展示编码、店铺、商品、轮次、周期、A/B 配置、目标、批准版本及审批记录。运营可维护“课堂模拟执行备注”；保存备注不等于真实投放。建议内容确认、归档的补充契约及联调检查见§5.3，不以主管批准或其他内容接口冒充这些操作。

### 3.9 FE-METRIC：经营数据回填及对比

运营从已批准实验选择日期及实验组。商品、店铺、轮次和实验由当前实验确定并只读展示，日期限定实验周期。提供手工新增、编辑已有行、批量导入入口和周期范围确认。

| 字段 | 必填与校验 |
| --- | --- |
| 业务日期、实验组 | 必填，日期采用 `YYYY-MM-DD`；组别来自该实验。 |
| 曝光、点击、订单 | 必填，非负整数，零是有效值。 |
| GMV、广告花费 | 必填，人民币元、非负金额，零是有效值。 |
| 详情页访问、详情页跳失 | 可选但成对填写，非负整数，跳失不超过访问；空值不自动转零。 |

保存后展示每日原始数值和派生指标，提供按日期走势、A/B 汇总和目标与实际差异表／图。筛选区域显示店铺、实验和期间，不直接输入或覆盖 CTR、转化率、ROI。重复日期／店铺／商品／实验／组记录不能当新实绩累加；提示跳过或更新，更新仅影响对应记录。

比率与金额口径按§4.5。对比图的指标、单位及目标方向一致；百分比差值标为“百分点”，ROI 差值标为“倍”，不可把两者混用。缺数据日显示缺失，图上不伪造零值趋势；部分数据统计明确覆盖范围。

周期结束后运营点击“确认复盘范围”，先展示实际日期范围、组别、缺失情况和汇总数据，再确认。后端确认并自动触发真实文字复盘，前端展示生成中，不立即再发一次复盘生成请求。范围已确认但生成失败时给出单独重试入口，保存数据及旧报告保持。

### 3.10 FE-REVIEW：复盘与下一轮

报告区域显示商品、轮次、店铺、实验、数据日期范围、数据快照／版本、报告版本和状态。左侧或顶部提供五部分目录，正文使用净化后的 Markdown 预览，运营可切换分析文字编辑、显式保存、确认、归档和历史版本查看。

| 固定部分 | 必需内容 |
| --- | --- |
| 单品全景信息 | 商品名称、品类、在售价格带、主推 SKU、竞品概要。 |
| 智能诊断总结 | 目标客群、卖点矩阵、转化卡点和价格竞争力。 |
| 视觉与内容资产 | 采纳的主图方向、视频脚本、关联优质素材及版本。 |
| 投放实验记录 | 策略、A/B 配置、审批人、时间、意见与执行备注。 |
| 经营复盘与后评价 | 目标与实际、流量／转化分析、已验证指标、归因推测及后续行动。 |

程序计算的统计表只读，运营可编辑 AI 分析文字，不能手改分析即改变统计事实。需要修改实绩时回到经营数据，再生成新报告版本；旧报告保持原快照。五部分缺失不能确认，调用失败保留数据及旧报告、提供原因和重试。

缺少详情页字段时写明“无法判断详情页跳失情况”；部分字段可计算时注明子范围及缺失日期，不当作全周期结论。事实、待验证归因和优化行动分别表达；“面料说明不足导致跳失”只能是待验证解释。

确认报告后运营可勾选有效优化行动，点击“创建下一轮诊断”。成功后进入新轮次，展示来源报告和所选行动；沿用商品档案，保留上一轮诊断、创意、任务、实验及数据。创建轮次不代表文字诊断已生成，新轮次仍经生成、编辑和确认；该操作不直接改价、备货或执行投放。未确认报告或未选行动时给出原因，主管只读。

### 3.11 FE-IMPORT：批量导入与数据中心

支持商品信息、SKU 库存、竞品资料、经营数据四类导入。运营可上传、预览与提交；两角色可下载模板和查看有权限的已有结果。工作台进入时携带业务上下文便于填写，但每行归属仍由后端核对。

| 步骤 | 展示及操作 | 完成结果／异常 |
| --- | --- | --- |
| 选择类型与模板 | 四类模板均提供 `.xlsx` 和 UTF-8 CSV 下载及填写说明。 | 明确金额单位、日期格式、必填字段和关联前置条件；下载失败可重试。 |
| 文件上传 | 拖拽或点击选择；显示文件名、类型及解析中状态。 | 不支持类型、不可解析文件、空表明确报错；重新选择清除旧映射及预览。 |
| 字段映射与初检 | 文件列映射至模板字段，展示原表预览、必填映射缺失、数字／日期错误。 | 表头一致时预填，运营可调整；多工作表文件选择一个数据表后映射；初检不代表最终通过。 |
| 后端预览 | 原文件及映射交由后端，显示批次、原始行号、字段、错误、待新增／更新／跳过。 | 预览不写业务数据；按有效、错误、重复过滤，错误行高亮且保留文字说明。 |
| 冲突选择 | 数据库重复选择跳过或更新；文件内重复组展示相关行、要求选择保留一行。 | 未解决的重复组不能提交；不按文件先后静默覆盖。 |
| 确认导入 | 展示选定处理及有效数量，允许运营确认有效行。 | 无有效行时不可提交；提交中防重复；后端再次校验归属和重复。 |
| 查看结果 | 新增、更新、跳过、失败数量；逐行结果及错误明细。 | 有效行独立成功，错误行可修正重导；不把部分成功显示为全部成功。 |

字段映射变化后旧预览失效，必须重新预览。数据提交只在确认步骤发生；刷新结果页通过批次标识重新查询，不再提交。错误明细可导出为 CSV 供修正，包含行号、字段、原因及相应原值；使用后端返回明细，未返回全量时不能把当前分页导出称为全部。

| 类型 | 模板必填字段 | 可选字段及业务要求 |
| --- | --- | --- |
| 商品 | `product_code`、`name`、`category`、`base_price` | 属性、主推规格；店铺及规格后续补齐，商品导入不代表全阶段完成。 |
| SKU 库存 | `shop_code`、`product_code`、`sku_code`、`stock_quantity` | `warning_threshold`；已有上架及映射，目标库存值替换原值并生成差额流水，不累计相加。 |
| 竞品 | `product_code`、`competitor_code`、`name`、`price` | 平台、规格、卖点、公开 URL／文本；导入为待核对。 |
| 经营 | `date`、`shop_code`、`product_code`、`experiment_code`、`group_code`、`impressions`、`clicks`、`orders`、`gmv`、`ad_spend` | `detail_visits`、`detail_bounces` 成对填写；批准实验、周期及组别正确。 |

后端每行涉及的关联记录或库存流水一起提交或回滚，前端以逐行结果展示。重导同一范围不会新增第二份实绩；导入结果页可查看批次及保存后的记录。文件大小、行数和服务端分页参数如有实现限制，需在上传处标明并与实际后端一致；本文不编造规格未规定的固定上限。

### 3.12 FE-SETTINGS：系统与服务配置

仅主管进入，包含文字模型、多模态演示、模拟授权及队列规则四块。分别查询、编辑、保存，显示修改人、时间及保存结果；运营不得读取配置详情。

| 配置区 | 字段与交互 |
| --- | --- |
| 真实文字模型 | 服务地址、模型名、脱敏密钥状态、温度、请求超时；默认文字超时六十秒，参数有效范围由后端校验。 |
| 密钥更新 | 当前值仅显示脱敏状态，另设“更新密钥”输入；未选择更新则不提交密钥字段，不能把掩码作为密钥。更新后清空输入并重新查询脱敏信息。 |
| 图片／视频 | 模拟模式、演示服务参数及来源说明，明确本教学版本使用演示素材；不承诺真实多模态接入。 |
| 平台授权占位 | 从已有店铺选择平台及接入标识，维护模拟脱敏授权状态；不录入平台密码或 Cookie。 |
| 队列规则 | 前端轮询间隔默认两秒、全局并发二、单次执行超时六十秒、最多两次自动重试；展示单位与首次之外重试的含义。 |

轮询间隔、并发及超时为正值，重试次数为非负整数；最终范围以服务端验证为准。页面解释超时／重试采用任务提交快照，新配置不改已运行尝试截止时间；并发是当前全局限制，调小不主动取消已运行任务。队列参数保存后，相关页面应读取主管配置的轮询规则，不硬编码两秒。

配置加载失败不得显示可编辑的空值并误覆盖；保存失败保留普通输入、明确未保存。密钥只发送后端使用，不进入 URL、日志或其他页面。规格未定义服务测试接口，本版不设置伪成功的“连接测试”；真实调用是否可用通过业务生成与实际错误反馈验证。

## 4. 公共交互规范

### 4.1 FE-UI：加载、空数据及反馈

首屏及区域查询显示骨架或加载状态，提交按钮显示处理中并禁用重复点击；查询成功后再移除。没有数据、加载失败、无权限分别使用不同提示。保存成功显示反馈并按返回标识重新读取；失败保留普通输入及原保存版本，不以页面本地值冒充持久化成功。

表单错误定位字段，导入错误定位原始行号与字段；非字段错误在区域顶部显示可读说明。对无法满足的阶段列出缺项和返回相应步骤的入口，不仅显示“操作失败”。通知不挡住表单主要按钮。

文字模型生成显示等待及补充说明，原内容仍可查看；失败后手动重试，不自动退回示例文字。普通刷新只重新查询，不触发生成、审批、导入、下一轮创建等写操作。

### 4.2 FE-EDIT：编辑、保存、确认及离开

显式保存与业务确认分离。编辑器及表单展示未保存状态；点击确认前要求先保存并确认所见版本，保存后的校验仍不满足时不给确认成功反馈。已确认内容修改保存新版本并重新确认，旧的引用不被替换。

内部切换商品、轮次、标签页、路由或关闭编辑弹窗时，若有未保存内容，提示“保存后离开／放弃修改／继续编辑”。保存失败则留在原上下文；放弃后恢复服务端原内容。刷新或关闭浏览器使用浏览器标准离开提示，不承诺关闭后自动恢复全部草稿。普通草稿只暂存内存，服务凭据不持久化为草稿。

取消任务、归档、提交主管审批、审批决定、复盘范围确认及下一轮创建前，展示操作对象、版本或范围，让用户核对影响。不能用通用“确定吗”代替必要的业务信息。

### 4.3 FE-SYNC：上下文、请求竞态及分页

商品、轮次是工作台共同上下文，诊断、创意、任务、素材、建议、实验、报告查询均携带必要归属。切换时清空上一上下文的数据展示并进入加载，停止旧视图轮询，取消能取消的请求或忽略旧响应；异步响应写入前核对当前上下文和请求序号。

店铺筛选变化后更新映射、库存、建议／实验及经营范围，商品和轮次保持。素材的合法跨店铺引用遵循后端校验，不通过重写归属实现。非法地址参数显示错误，不用其他商品数据填充。

页码、每页条数及筛选在当前路由访问期间保留；刷新从地址中的上下文及筛选恢复可支持的内容，默认未记录筛选恢复业务默认值。默认每页二十条、可选二十／五十／一百，接口参数名称依契约映射；总数及页数使用后端返回。空页面可回第一页，不能隐藏仍存在的筛选条件。

### 4.4 FE-HISTORY：版本与文件预览

内容、建议、素材及报告显示版本、状态、归属、来源和相关操作记录。新版本保存后从服务端重新读取；历史只读，明确显示被哪个创意、任务、实验或报告引用。归档退出新选择，不删除历史快照或文件。

所有图片／视频通过带鉴权的后端文件请求取得，前端可用临时对象 URL 展示，关闭预览、切换上下文或退出时释放。JWT 不放入文件 URL 查询参数；鉴权失败与文件缺失分别提示。视频使用实际播放控件验收，封面可见不代表可播放。预览、富文本及 Markdown 展示均进行内容净化，不能执行保存内容中的脚本。

### 4.5 FE-NUMBER：日期、金额与指标

业务日期采用 Asia/Shanghai 自然日的 `YYYY-MM-DD`，不能因 UTC 转换偏移一天；操作时间按服务端时间转为本地展示并注明时区。金额统一人民币元，提交及保存采用十进制口径，前端不使用浮点运算决定业务金额；整数计数不带小数。

| 指标 | 公式／规则 | 展示 |
| --- | --- | --- |
| CTR | 点击数 ÷ 曝光数。 | 百分比，两位小数。 |
| 转化率 | 订单数 ÷ 点击数。 | 百分比，两位小数。 |
| ROI | GMV ÷ 广告花费。 | 两位小数及“倍”，注明本项目广告投入产出比口径。 |
| 详情页跳失率 | 详情页跳失次数 ÷ 详情页访问次数。 | 百分比，两位小数；缺失字段时无法判断。 |
| 在售动销率 | 所选期间有订单的在售商品数 ÷ 该范围在售商品总数。 | 按商品去重，百分比，两位小数。 |
| 在售价格带 | 当前商品在售店铺 SKU 售价最小至最大值。 | 人民币范围，不用统一基础价冒充各店实际售价。 |

跨日期、组别、店铺先求原始数据之和再计算比率，不能平均每日比率；比较使用未舍入值，展示采用两位小数。统计结果优先使用后端计算值。输入目标标注百分比／倍数，界面单位与接口表示的转换在实际契约中统一，不能把 `2.20%` 错传成无单位的另一量级。

分母为零显示“不可计算”，不显示 `0%`、`Infinity` 或 `NaN`。缺失原始数据标为缺失，不能当零；详情字段仅部分齐备时展示可计算子范围及覆盖情况，完整周期的跳失结论保持无法完整判断。目标与实际必须同商品、店铺、实验、周期和口径。

## 5. 接口对接要求

### 5.1 公共契约与错误处理

所有业务 API 均加 `/api` 前缀。登录之外携带 Bearer token；普通请求为 JSON，文件上传为 multipart。创建成功 201，任务受理 202；实际返回对象、字段及分页封装由 Pydantic 契约提供。以下映射均引用 `SPEC.md` §6，不表示已有运行接口。

| 返回状态／情况 | 前端处理 |
| --- | --- |
| 401 | 停止业务请求、清除失效凭据并进入登录；草稿处理按§2.1，不自动重放写请求。 |
| 403 | 显示无权限及返回入口；不声称操作成功。 |
| 404 | 显示资源不可访问／不存在，返回有效列表；不显示缓存中其他对象。 |
| 409 | 显示版本、状态或归属冲突，保留用户输入；重新读取最新状态后由用户修正。 |
| 422 | 将字段／行错误映射到表单或预览，保留普通输入。 |
| 502／504 | 显示文字模型服务失败／超时，保留原版本及数据，提供显式重试。 |
| 网络中断／其他服务错误 | 显示无法完成及重试；写操作结果不明时先查询可用结果，禁止自动盲目重发审批、导入等请求。 |

错误应含错误代码、可读说明和字段／行明细，前端不另造后端错误格式。内容返回须能核对商品、轮次、版本、上游引用及状态；任务返回须能判断自动重试与真正终态；导入返回须关联原始行。重复提交同时由前端请求中控制和后端业务唯一约束防止。
